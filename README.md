# Agent for ZCH

面向建设工程检测行业的企业级知识库 Agent，帮助检测人员更快查询规范依据、整理项目资料、分析质量缺陷，并通过可控的工具调用衔接企业业务流程。

> 本仓库仅用于产品与技术能力展示，核心源代码未公开。项目支持企业私有化部署、知识库建设与业务场景定制。

[在线体验](https://agent.mapleai.top/) · [联系作者](mailto:yuyuezhou1@gmail.com)

## 核心能力

- **行业知识问答**：从检测规范、内部资料和历史案例中检索依据并生成可追溯回答。
- **项目辅助分析**：支持检测周期、检测方案、IDI 缺陷、合同字段、文档与图片分析等场景。
- **企业知识库治理**：支持 PDF、Word、Excel 与扫描文档解析、切片、向量化、来源追溯和文档状态管理。
- **用户长期记忆**：会话总结、个人画像和 Obsidian Markdown 笔记按账号保存并在后续对话中使用。
- **权限与安全**：提供管理员、普通用户和游客角色；知识文档、个人记忆和业务数据在服务端强制隔离。
- **工具与自动化**：支持定时任务、失败诊断、文件处理、业务工具调用及 MCP 接入。
- **工程化交付**：支持 Docker Compose、Nginx、健康检查、自动测试、镜像发布和可回滚部署。

## 技术架构

```text
用户 / Web 前端
      ↓
身份认证与权限控制
      ↓
LangGraph Agent 编排
  ├─ 行业知识检索（RAG）
  ├─ 用户长期记忆
  ├─ 文档与图片处理
  ├─ 业务工具 / MCP
  └─ 定时任务与人工确认
      ↓
FastAPI / Qdrant / SQLite / Markdown
      ↓
Docker Compose / Nginx / GitHub Actions
```

## 技术选型

| 层级 | 方案 |
|---|---|
| 大模型 | DeepSeek 或其他 OpenAI 兼容接口 |
| Agent 编排 | LangGraph / LangChain |
| 向量检索 | Qdrant + BAAI/bge-base-zh-v1.5 |
| 服务端 | FastAPI / Python |
| Web 前端 | Next.js / React |
| 数据 | SQLite 元数据 + Qdrant 向量 + Markdown 用户笔记 |
| 部署 | Docker Compose / Nginx / Linux |
| 工程质量 | Pytest / Ruff / GitHub Actions |

## 项目亮点

1. **不是简单聊天套壳**：Agent 可根据用户目标选择知识检索、文件分析或业务工具。
2. **高风险数据不依赖模型自觉**：权限在认证、数据库查询和向量检索层强制执行。
3. **知识与行为分层**：行业资料通过 RAG 更新，金额计算和业务操作交给确定性工具。
4. **面向生产环境设计**：包含审计、异常诊断、健康检查、测试、发布和失败回滚机制。
5. **模型供应商可切换**：通过兼容接口降低对单一模型服务商的依赖。

## 适用场景

- 建设工程检测规范与内部制度问答
- 检测方案、工作量和周期辅助分析
- 工程质量潜在缺陷检索与分类
- 合同、报告、Excel 与扫描件处理
- 企业内部知识助手与员工长期记忆
- 与现有 ERP、BPM、检测管理平台的 API / MCP 集成
